An addon for [Primary Skill Evolution](https://thunderstore.io/c/risk-of-rain-returns/p/GreenAlen22/PrimarySkillEvolution/) that brings its primary attack rework to survivors from other mods.  
Install it next to Primary Skill Evolution and any of the survivor mods below. Only the survivors you have installed are affected; the rest are skipped.

How each mechanic works - magazine, active reload, mouse aim, stamina, finisher, series, lunge, launcher - is in the [Primary Skill Evolution wiki](https://github.com/GreenAlen22/rorr-PrimarySkillEvolution/wiki). The numbers for every survivor here are in the [addon wiki](https://github.com/GreenAlen22/rorr-PSE-Modded-Survivors/wiki).

## Melee
Stamina, finisher and Rage, series, lunge and launcher. Of the survivor's own skills, only the primary spends stamina and fills the finisher; the lunge and launcher spend it as for vanilla. These survivors have no signature effect of their own. Instead, the finisher shows one shared blast in the survivor's color, and Rage is stronger than vanilla's: +50% damage instead of +35%, 15% lifesteal instead of 10%, and +20% attack speed, for the same 8 seconds.

## Charge window
MULE (Interference Removal) - release the charge inside the window and the punch goes out as the full-charge slam, with Steady Hand.  
Captain (Vulcan Shotgun) - release inside the window for a full-charge volley: no spread, full range.  
The window covers 65-85% of the charge. With Skills++, each level of the primary widens it.
